# Data Dictionary

## CDC PLACES (County Level, GIS Friendly)
- **Source:** CDC PLACES 2025 release via BRFSS
- **Granularity:** One row per county
- **Key measures:**
- **Columns General:** Extensive chronic disease data by county

## NCHS Life Expectancy by State & Sex
- **Source:** National Vital Statistics System
- **Granularity:** State-level, by Sex
- **Years:** 2018-2021
- **Columns:** "State","County","Census Tract Number","Life Expectancy","Life Expectancy Range","Life Expectancy Standard Error"

## USALEEP Life Expectancy
- **Source:** U.S. Small-area Life Expectancy Estimates Project
- **Granularity:** Census tract level
- **Years:** 2010-2015
- **Columns:** "State","Sex","LEB","SE","Quartile"
